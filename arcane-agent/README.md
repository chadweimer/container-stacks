# Arcane Agent

Arcane Agent runs on a Docker host to connect it to a central [Arcane](https://getarcane.app/) Manager instance.

## Initial Setup

1. In your Arcane Manager dashboard, create or register an agent to obtain an `ARCANE_AGENT_TOKEN`.
2. Configure `ARCANE_AGENT_TOKEN` and `ARCANE_MANAGER_API_URL` in `.env`.
3. Deploy the stack.
