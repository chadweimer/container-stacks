# Arcane

## Initial Setup

### Secrets

Per the [Arcane documentation](https://getarcane.app/docs/get-started/installation#install-with-docker-compose), you can generate the values for the `ARCANE_ENCRYPTION_KEY` via `openssl rand -hex 32`.

## Post Bring-up

### Authelia

Follow the guide at <https://www.authelia.com/integration/openid-connect/clients/arcane/>, specifically following the "Web GUI" section for the Arcane configuration.
