# Portainer

Portainer CE/EE and Portainer Agent for managing Docker environments, containers, and stacks.

## Initial Setup

1. On first run, access Portainer at port `9000` or `https://portainer.${BASE_DOMAIN}`.
2. Create your initial admin credentials.
3. Add your container template registries:
   - Point to `templates.json` in this repository for Portainer app templates.
