# Wine & Cats (GOMP)

Go Meal Planner (GOMP) recipe manager and PostgreSQL database.

## Initial Setup

1. Configure `DB_PASSWORD`, `SECURE_KEY`, and `STAGE` in `.env`.
2. Deploy the stack. Access GOMP at `https://${STAGE}.${BASE_DOMAIN}` and Adminer database management at `https://db.${STAGE}.${BASE_DOMAIN}`.
